Mayo, R., Zlydenko, O., Bootbool, M., Fronman, S., Gilon, O., Hassidim, A., Kratzert, F., Loike, G., Matias, Y., Nakar, Y., Nearing, G., Sayag, R., Sicherman, A., Zemach, I., & Cohen, D. (2026). Changes made by RippleEffect AI: spatially selected valid polygon/multipolygon records intersecting [-88,24,-79,32]; converted WKB to GeoJSON; added derived bounding boxes and a source URL; preserved original UUIDs, start/end dates, area_km2 values and full polygon coordinates without clipping or simplification. The subset contains 16,737 records from the 2,646,302 original records scanned. Original import metadata is embedded in the GeoJSON file.

The added review rules, classifications and application estimates are RippleEffect AI's prototype behavior. Google and the original authors have not endorsed this project. Historical geocoded record areas are not parcel-level flood extents or probabilities.

## Place-name lookup

City/place search uses Open-Meteo Geocoding and GeoNames location data: https://open-meteo.com/en/docs/geocoding-api . Queries run only on explicit submission and are cached. Prepared Florida demo area centers remain available without a remote lookup. Results represent place centers, not property boundaries.
